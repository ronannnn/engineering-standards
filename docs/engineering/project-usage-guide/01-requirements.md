# 需求分析：项目接入与使用说明

## 背景与目标

### 问题

现有 README 混用了标准库与业务项目的路径，没有 Agent 接入说明，也没有自然语言与程序命令的职责说明。

### 目标

提供 SETUP 和可照做的 README，说明接入、开始需求、续做、检查及升级方法。

### 非目标

不实现新的 CLI、插件、消息服务或自动升级器，不改门禁判据。

## 现有系统分析

复用脚手架、模块初始化和 gates/run.py，脚本通过自身位置找模板，向当前业务目录写产物。现有技能引用 ../../policies，接入必须保留完整的目录关系；业务项目原有规则和 CI 不能直接覆盖。

## 术语

接入：配置某个业务项目使用本标准。快捷指令：开发工具提供的可选聊天入口。程序命令：实际执行初始化或校验的现有脚本。

## 功能需求

### FR-1 补齐项目接入与使用方法

- 描述：SETUP 引导 Agent 检查、接入、验证与升级；自然语言触发流程，现有脚本实际执行。
- 优先级：必须
- 场景：
  - Given：已有业务项目和标准仓库。
  - When：用户要求接入并开始一项需求。
  - Then：保留原规则，生成项目配置和可定位的产物，能从业务根调用门禁，不声称存在未实现的命令。

## 非功能需求

新增运行依赖 0 个；使用 Python 3.12 作为已验证环境；原有 87 项测试和两份样例保持通过。
