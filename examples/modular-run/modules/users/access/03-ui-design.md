# UI/UX 设计：优惠券批量导入

## 页面清单

| 页面 | 路由/入口 | 关键 | 复用组件 | 新增/修改 |
|---|---|---|---|---|
| 优惠券导入 | `/coupon/import` | 是 | `UTable`、`UFileUpload`、`UAlert` | 新增 |
| 优惠券列表 | `/coupon` | 否 | `v-nuxt-ui` 数据表格 | 修改：新增批次筛选 |

## 关键流程

1. 运营从优惠券列表点「批量导入」进入导入页。
2. 下载模板（或直接拖入已有 CSV）→ 触发预览。
3. 预览区显示总行数、合法行数；若有错误，错误表格按行号排序，运营修正后重新上传。
4. 全部合法时「确认导入」按钮可用 → 点击 → 展示批次号与导入数量。
5. 运营可跳转列表页按批次号筛选，或直接在该页撤回本批次。

## 设计系统与复用

- 表格与分页复用 `@nuxt/ui` 的 `UTable`；上传复用 `UFileUpload`，不自定义拖拽区。
- 颜色与间距只用现有 token（`primary-600`、`gray-*`），错误态用 `red-500`，不新增色值。
- 错误提示复用 `UAlert` 的 warning/error 变体，不新造 toast。
- 新增组件只有一个：`ImportPreviewTable.vue`，归属 `components/coupon/`。

## 布局与响应式

- 桌面优先：内容区最大 1200px，预览表格横向可滚动。
- 断点 < 768px：上传区与预览表格上下堆叠，操作按钮固定在底部安全区内。
- 打印与邮件场景不适用。

## 交互与状态

- 空状态：未上传时展示模板下载卡片与字段说明，不显示空表格。
- 加载状态：预览与确认均用按钮内 spinner + 禁用重复点击，超过 3 秒追加「正在处理，请勿刷新」。
- 错误状态：文件类型/大小错误用 `UAlert` 顶部条；行级错误进表格；网络错误保留已选文件并允许重试。
- 无权限状态：无 `operator:coupon:import` 时整页替换为无权限提示，不显示上传入口。
- 成功反馈：确认后顶部展示批次号（可复制）与数量，并给出「查看该批次」与「继续导入」两个动作。
- 危险操作确认：撤回批次需二次确认弹窗，写明影响数量并需输入批次号后四位。

## 可访问性

- 键盘可达：上传、预览、确认、撤回均可 Tab 到达，顺序与视觉顺序一致。
- 对比度：正文与背景对比度 ≥ 4.5:1，错误红字在浅底上 ≥ 4.5:1。
- 语义：错误表格用 `role="alert"` 区域包裹，行号列使用 `<th scope="row">`。
- 屏幕阅读器：确认导入后的批次号通过 `aria-live="polite"` 播报。

## 视觉验收标准

| 编号 | 页面 | 判定标准 | 检查方式 | 可自动化 |
|---|---|---|---|---|
| VAC-1 | 导入页 | 三步骤（上传/预览/确认）在同一视口内可见，无需滚动即可看到主按钮 | 截图人工核对 | 否 |
| VAC-2 | 导入页 | 错误表格行高与正文一致，行号列右对齐，错误原因不换行溢出 | 截图 + Playwright 尺寸断言 | 是 |
| VAC-3 | 导入页 | 撤回确认弹窗必须包含批次号与影响数量 | 组件测试断言文案 | 是 |

## 交付说明

- 组件：`ImportPreviewTable.vue`、`ImportStepper.vue`（复用 `UStepper` 组合）。
- Token：`primary-600`（主按钮）、`red-500`（错误）、`gray-50`（空状态底）。
- 文案：空状态引导语、错误原因模板（`第 {line} 行「{field}」：{reason}`）、成功提示。
- 资源：模板下载图标复用 `i-heroicons-arrow-down-tray`。
